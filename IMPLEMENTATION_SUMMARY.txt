================================================================================
HOW TO USE
================================================================================

BASIC USAGE:
  import { getCorrectHref } from "@/lib/link-validator"
  
  <Link href={getCorrectHref("/career")}>
    Career
  </Link>

WITH REACT HOOK:
  import { useValidateLink } from "@/hooks/useValidateLink"
  
  const validation = useValidateLink("/career")
  // Shows console warning if broken in dev mode

DEBUG PANEL:
  import { LinkValidatorDebug } from "@/components/debug/LinkValidatorDebug"
  
  <LinkValidatorDebug links={footerLinks} />
  // Shows in bottom-right in dev mode

================================================================================
ADDING NEW PAGES
================================================================================

When you create a new page:

1. Create the page file: app/my-page/page.tsx

2. Add to valid routes in lib/link-validator.ts:
   const VALID_ROUTES = [
     "/",
     "/my-page", // ← Add this
   ]

3. Update links in footer or other components to use getCorrectHref()

================================================================================
FIXING BROKEN LINKS
================================================================================

Option 1: Create a permanent redirect
  const LINK_REDIRECTS: Record<string, string> = {
    "/old-page": "/new-page",
  }

Option 2: Temporary "coming soon" redirect
  const LINK_REDIRECTS: Record<string, string> = {
    "/coming-soon": "/",
  }

Once page is created:
  - Remove from LINK_REDIRECTS
  - Add to VALID_ROUTES
